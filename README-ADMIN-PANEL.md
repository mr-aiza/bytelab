# پنل مدیریت بایت‌لب — راهنمای نصب

این پکیج شامل یک **Worker اختصاصی برای پنل مدیریت** (`bytelab-admin-worker.js`)
و صفحه‌ی پنل (`admin.html` + `assets/admin-theme.css`) است. این Worker کاملاً
جدا از `bytelab-telegram` اجرا می‌شود، اما از همان **KV Namespace (`LEADS_KV`)**
استفاده می‌کند تا داده‌ها (لیدها، بلاگ، FAQ، گالری نمونه‌کار، بنر، وضعیت
آنلاین/آفلاین) بین پنل وب و ربات تلگرام کاملاً مشترک و هم‌زمان باشند.

## فایل‌های این پکیج

| فایل | توضیح |
|---|---|
| `bytelab-admin-worker.js` | کد کامل Worker پنل مدیریت |
| `wrangler-admin.toml` | تنظیمات دیپلوی این Worker |
| `admin.html` | صفحه‌ی پنل مدیریت |
| `assets/admin-theme.css` | قالب اختصاصی پنل (رنگ‌بندی فیروزه‌ای/بنفش بایت‌لب) |

## ۱) ساخت Worker جدید در Cloudflare

1. در Cloudflare Dashboard وارد بخش **Workers & Pages** شو.
2. یک Worker جدید با نام `bytelab-admin` بساز (یا با `wrangler deploy` و فایل
   `wrangler-admin.toml` دیپلویش کن).
3. کد `bytelab-admin-worker.js` را در آن قرار بده.

## ۲) اتصال به همان KV Namespace وورکر تلگرام

در `wrangler-admin.toml`، مقدار `id` زیر `[[kv_namespaces]]` را دقیقاً برابر
همان `id` ای بگذار که در تنظیمات `bytelab-telegram` زیر **`LEADS_KV`** استفاده
شده. با داشبورد Cloudflare: Settings → Bindings → KV Namespace Bindings →
همان namespace با نام `LEADS_KV` وصل کن.

## ۳) متغیرهای محیطی (Secrets)

از Settings → Variables and Secrets این Worker جدید:

- `ADMIN_PANEL_PASSWORD` — رمز عبور ورود به پنل وب (Secret، **اجباری**؛ یک
  رمز قوی انتخاب کن — جدا از هر رمز دیگه‌ای که جای دیگه استفاده می‌کنی)
- `TELEGRAM_BOT_TOKEN` — همون توکن ربات تلگرام (Secret، اختیاری — فقط برای
  ارسال فایل بک‌آپ به تلگرام لازمه)
- `TELEGRAM_CHAT_ID` — چت‌آیدی خودت (Secret، اختیاری — فقط برای بک‌آپ)

و به‌صورت Variable عادی (اختیاری):

- `ADMIN_SESSION_HOURS` — مدت اعتبار نشست ورود، به ساعت (پیش‌فرض ۱۲)
- `ADMIN_ALLOWED_ORIGIN` — دامنه‌ی مجاز CORS (پیش‌فرض `*`؛ بهتره
  `https://bytelabpro.xyz` بذاری)
- `AI_ENDPOINT` — آدرس Worker هوش‌مصنوعی bytelab-ai (پیش‌فرض همون آدرسی
  که در editor.js هست)

## ۴) وصل کردن admin.html به Worker جدید

در پایین فایل `admin.html`، خط زیر را با آدرس واقعی Worker جدید جایگزین کن:

```js
const API_BASE = "https://bytelab-admin.YOUR_SUBDOMAIN.workers.dev";
```

سپس `admin.html` و `assets/admin-theme.css` را کنار بقیه‌ی فایل‌های سایت
(در همون ریپازیتوری GitHub Pages) قرار بده. اگه می‌خوای فقط خودت بهش دسترسی
داشته باشی، بهتره این صفحه رو با یه اسم غیر قابل‌حدس (نه دقیقاً `admin.html`)
منتشر کنی یا طبق چیزی که قبلاً گفته شد، ریپو رو خصوصی/پلن Pro کنی — چون ورود
با رمز محافظت می‌شه، ولی خود صفحه‌ی HTML همیشه از دید عموم قابل مشاهده‌ست.

## ۵) تست

1. `admin.html` را باز کن، با رمز `ADMIN_PANEL_PASSWORD` وارد شو.
2. یه پست بلاگ یا سوال FAQ اضافه کن — باید بلافاصله از ربات تلگرام هم دیده
   بشه (چون از همون KV می‌خونه).
3. از دکمه‌ی «نوشتن با AI» تو بخش بلاگ یه پیش‌نویس بساز.
4. از منوی «لاگ فعالیت‌ها» ببین عملیات‌هات ثبت شده باشن.

## نکات امنیتی

- تلاش‌های ناموفق ورود محدود شده: بعد از ۵ بار رمز اشتباه، IP به مدت ۱۵
  دقیقه موقتاً قفل می‌شه.
- نشست ورود (Token) در KV با انقضای خودکار ذخیره می‌شه.
- توصیه می‌شه `ADMIN_ALLOWED_ORIGIN` رو روی دامنه‌ی واقعی سایتت تنظیم کنی.

## بعداً می‌تونیم اضافه کنیم

طبق چیزی که گفتی، فعلاً همه‌چی یکجا ساخته شد (بلاگ، FAQ، گالری، بنر، وضعیت،
لیدها، آمار، بک‌آپ). اگه بعداً خواستی، این‌ها هم قابل اضافه‌شدنه:

- سیستم چند-ادمین با رمز جدا (مثل co-admin ریحون) به‌جای رمز تکی فعلی
- مدیریت مستقیم APK / لینک بازار از پنل وب
- ویرایش تنظیمات ویجت چت AI از پنل وب
